# Walkthrough: Persiapan Basis Data Lokal

Semua tahapan inisialisasi basis data lokal untuk proyek **Analisis Sentimen Kebijakan Publik Berbasis AI** telah berhasil dilakukan sesuai dengan rencana implementasi.

## Perubahan yang Dilakukan

1. **Membuat Berkas Database Setup:**
   - Membuat file [setup_database_sqlite.py](file:///d:/GitHub/socmed-sentimen-analysis-pp/setup_database_sqlite.py).
   - Skema tabel `log_cuitan` diselaraskan agar menggunakan nama kolom bahasa Inggris yang konsisten dengan modul scraping dan analitik.
   - Kolom `tweet_id` diset sebagai `PRIMARY KEY` untuk mencegah duplikasi data.
   - Ditambahkan metrik interaksi `likes` dan `retweets`.

2. **Pemasangan Dependensi:**
   - Menginstal library `pandas` ke dalam virtual environment (`unpar`) untuk mendukung proses load/baca data ke DataFrame.

3. **Penanganan Unicode Emojis:**
   - Menghapus output emoji terminal pada fungsi print di script python dan menggantinya dengan tag ASCII seperti `[OK]`, `[SUCCESS]`, `[ERROR]`, dan `[DATA]` untuk mencegah terjadinya `UnicodeEncodeError` pada konsol Windows dengan encoding CP1252.
